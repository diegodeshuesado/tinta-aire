# Tinta al aire

Pinta trazos en el aire con la mano frente a la cámara. Cada trazo es una voz.

- **Pellizco pulgar + índice:** dibuja. La altura da el tono, el movimiento lateral es el arco.
- **Índice apuntando en círculos:** la pintura orbita alrededor de ti y el sonido gira con ella.
- **Mano en "C" quieta:** abre o cierra la C para cambiar el tamaño. Abre la mano para soltar.
- **Brazos en X:** todo se derrite y se reinicia.
- **Teclas:** `S` estilo (tinta / cromo), `C` cámara, `M` silencio, `X` derretir, `P` panel MIDI.

Funciona en Chrome o Edge. Necesita cámara; MIDI es opcional (Web MIDI).
Seguimiento de manos con MediaPipe Hand Landmarker.
